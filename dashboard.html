Token Doctrine

Artifact Supports. Token Closes.

Submitted artifacts are used as reference only. Token issuance represents client-declared completion of execution. The system records acknowledgement, not verification of real-world outcomes.

Payment does not equal progression. Subscription state and progression state are separate. PSEQ advances only through issued token records inside the active cycle.
